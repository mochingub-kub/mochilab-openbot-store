AI teammates ทำงานอยู่ใน Docker ของ Umbrel ส่วนการแชตและจัดการ Agents ใช้เว็บ OpenBot ด้วยบัญชีเดียวกัน

เปิด OpenBot Web App →

เชื่อมบัญชีครั้งแรก

เปิด Terminal/SSH ของ UmbrelOS Host แล้วใช้คำสั่งนี้ เพียงครั้งแรก หลังติดตั้งแอปสำเร็จ:

sudo docker exec -it mochilab-openbot_openbot_1 openbot login

ใส่อีเมลและรหัสยืนยันใน Terminal เท่านั้น ไม่ต้องส่งรหัสในแชต จากนั้นเปิดเว็บ OpenBot ด้านบนด้วยอีเมลเดียวกัน แล้วเลือกเซิร์ฟเวอร์ที่เพิ่งเชื่อมต่อ

หากคำสั่งหา Container ไม่พบ ให้ตรวจสถานะของแอปใน Umbrel และชื่อจริงด้วย sudo docker ps --format '{{.Names}}'

หน้านี้เป็นเพียง Launcher/คู่มือตั้งค่า ไม่ใช่หน้าจัดการ Agents หรือการยืนยันว่า OpenBot เชื่อมต่อสำเร็จ แอป Agent ไม่มีพอร์ตเข้าจากภายนอกและใช้การเชื่อมต่อขาออกตามเอกสารผู้พัฒนา อ่านคู่มือ Docker
