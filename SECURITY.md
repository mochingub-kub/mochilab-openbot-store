# Security and privacy

This is an unofficial personal-use community package, provided **as-is** with **no guaranteed technical support, maintenance, or bug fixes**.

Please **do not post security vulnerabilities publicly**, and never attach production app data, database files, configuration secrets, provider sessions, API tokens, keyrings, private backups, or unredacted diagnostics to issues or pull requests.

For a sensitive report, use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, do not post secrets or exploit details in a public issue. No response time, investigation, or remediation is guaranteed.

This community package is not an official Nightly Labs or Umbrel release. A packaging-specific problem should not be reported as a security incident in upstream OpenBot unless you have independently confirmed that the upstream software is affected.

For your own installation, keep administrator access private, review the packaged permissions, and make verified offline backups before updating. If you believe a credential has already been published, revoke or rotate it in the affected provider immediately. Removing a file from a branch does not erase it from Git history or forks.
